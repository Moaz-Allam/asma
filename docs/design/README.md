## Rules

- Copy layout and component shapes from the references. **Colours, fonts, radius, and spacing come
  from `context/ui-tokens.md`**, which records the brand values (blocker B4) with a measured contrast
  table. Our rules (`context/ui-rules.md`) win over any reference.
- Every screen must work at 390px first, in `ar` (right to left), `tr`, and `en`.
- For each page spec, `/architect` asks where the design comes from: this folder, screenshots, the
  existing UI and tokens, or a suggested direction. Never assume.
- List here what is excluded from a reference (for example urgency badges or patterns the brief does
  not include), so it is not copied by accident.
